# Links das Telas da Aplicação

Com o servidor de desenvolvimento rodando localmente (normalmente através do comando `npm run dev`), você pode acessar as telas da aplicação através dos seguintes endereços:

## Telas Públicas
*   **Página Inicial (Landing Page):** [http://localhost:5173/](http://localhost:5173/)
*   **Login / Cadastro:** [http://localhost:5173/cadastro](http://localhost:5173/cadastro)
*   **Registro (Criação de Conta):** [http://localhost:5173/registro](http://localhost:5173/registro)
*   **Início do Marketplace:** [http://localhost:5173/marketplace](http://localhost:5173/marketplace)
*   **Categorias do Marketplace:** [http://localhost:5173/marketplace/category](http://localhost:5173/marketplace/category)
*   **Página de uma Loja Específica:** [http://localhost:5173/loja/ID_DA_LOJA](http://localhost:5173/loja/1) *(Substitua "ID_DA_LOJA" pelo ID real de uma loja, ex: `/loja/1`)*
*   **Preview da Loja (Marketplace Store):** [http://localhost:5173/marketplace/store](http://localhost:5173/marketplace/store)

## Telas Protegidas (Exigem Login)
*   **Seleção de Negócio:** [http://localhost:5173/selecao-negocio](http://localhost:5173/selecao-negocio)
*   **Planos e Assinaturas:** [http://localhost:5173/planos](http://localhost:5173/planos)
*   **Perfil do Usuário/Lojista:** [http://localhost:5173/perfil](http://localhost:5173/perfil)

> **Nota:** Para visualizar as telas protegidas, você precisará estar logado na aplicação. Se você tentar acessar uma tela protegida sem estar logado, o sistema o redirecionará para a tela de login.
